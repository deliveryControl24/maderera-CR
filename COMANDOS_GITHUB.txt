 0. CHECKLIST DE CADA ACTUALIZACION (SIEMPRE)
------------------------------------------------------------
# 1) Bump APP_VERSION en config_paths.py
# 2) Generar zip + version.json:
python3.11 empacotar_update.py 2.6.1 "Bugs corregidos: ..."
# 3) Commit SIEMPRE incluye version.json
git add config_paths.py app.py main.py modulos.py version.json updates/latest.zip
git commit -m "v2.6.1: descripcion"
git push origin main
# 4) Si hay EXE Windows: compilar APARTE (build_exe.bat) -> copiar a updates\
#    luego doble clic PUBLICAR.bat (solo sube, NO compila; lee APP_VERSION)
# 5) Verificar:
#    https://raw.githubusercontent.com/deliveryControl24/maderera-CR/main/version.json
# NOTA: ACTUALIZADOR.exe = cliente. PUBLICAR.bat = publicar (sin compilar).
#       build_exe.bat = compilar EXE. No hay PUBLICAR_26X.bat.

------------------------------------------------------------
 3. SUBIR ACTUALIZACION DEL SISTEMA (auto-update)
------------------------------------------------------------
# El updater ahora usa SIDE-BY-SIDE:
#   versions\<nueva>\  +  current.txt  +  INICIAR.bat
# No pisa el EXE en uso. La app cierra sola y relanza la nueva.

# REGLA: SIEMPRE version.json + zip/EXE en el mismo push

# OPCION A - ZIP liviano (SIN compilar) - codigo .py (Mac/portable)
python3.11 empacotar_update.py 2.6.1 "Lista de cambios"
git add -A
git commit -m "Update zip 2.6.1"
git push
# Sube updates/latest.zip + version.json
# Cliente: descarga zip -> versions/2.6.1/*.py -> current.txt -> relanza

# OPCION B - EXE en la NUBE (GitHub Actions) - RECOMENDADO para Windows
git tag v2.6.1
git push origin v2.6.1
# -> Actions arma dist/PINO_SYSTEM.exe solo
# -> Crea Release de GitHub con el EXE
# Bajar el EXE del Release y:
#   updates/PINO_SYSTEM.exe + version.json -> git add ...

# OPCION C - EXE a mano en Windows (si Actions no esta activo)
build_exe.bat
copy /Y "dist\PINO_SYSTEM.exe" "updates\PINO_SYSTEM.exe"
# version.json DEBE quedar con la MISMA version que el EXE
git add version.json updates/PINO_SYSTEM.exe
git commit -m "Release v2.6.1"
git push

# Despues de la 1a actualizacion side-by-side, abrir con INICIAR.bat

# El sistema de los clientes lo detecta al iniciar o con ACTUALIZAR Sistema
